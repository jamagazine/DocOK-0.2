# Обзор проекта DocOK v0.2

## Описание

DocOK — это веб-приложение для автоматизированной обработки и анализа документов снабжения (спецификаций, счетов, смет). Система использует AI-технологии для извлечения данных из PDF и Excel файлов, их структурирования и сопоставления позиций между документами.

## Архитектура

Проект построен по архитектуре клиент-сервер:

### Frontend (React + TypeScript)
- **Технологии**: React 18, TypeScript 6, Vite 6, TailwindCSS 4
- **UI-библиотеки**: Radix UI, Lucide Icons, Motion (анимации)
- **Управление состоянием**: React Context API (DataContext)
- **Роутинг**: React Router v7
- **Работа с документами**: PDF.js, ExcelJS, XLSX

### Backend (Python + FastAPI)
- **Фреймворк**: FastAPI
- **AI-интеграция**: Yandex Cloud (GPT, OCR)
- **Обработка документов**: pandas, pdfjs, openpyxl
- **Валидация**: собственные валидаторы (ИНН, КПП, БИК, расчетные счета)

## Основной функционал

### 1. Трехэтапный рабочий процесс

Приложение организовано в виде трех последовательных этапов (stages):

- **Спецификация (spec)**: Загрузка и обработка спецификаций материалов
- **Счета (invoice)**: Загрузка счетов от поставщиков
- **Смета (estimate)**: Автоматическое формирование сметы на основе сопоставления

### 2. Обработка документов

**Поддерживаемые форматы:**
- PDF (цифровые и отсканированные)
- Excel (XLS, XLSX)
- Автоматическое определение типа документа

**Методы обработки:**
- Локальный парсинг (для цифровых PDF и Excel)
- OCR через Yandex Vision (для сканов)
- AI-анализ через Yandex GPT (извлечение структурированных данных)

### 3. Интеллектуальное извлечение данных

**Для спецификаций:**
- Позиция, наименование, бренд, код
- Единицы измерения, количество
- Иерархическая структура (разделы, группы)

**Для счетов:**
- Реквизиты поставщика (название, ИНН, КПП)
- Позиции товаров (артикул, цена, количество, НДС)
- Условия оплаты и доставки
- Валидация математики (цена × количество = сумма)

### 4. Сопоставление позиций

- Автоматическое сопоставление позиций из счетов с позициями спецификации
- Использование алгоритмов нечеткого поиска (fuzzy matching)
- Визуальная индикация качества совпадений (perfect/warning/none)

### 5. Управление проектами

- Создание и управление несколькими проектами
- Хранение истории операций
- Экспорт данных (JSON, Excel)
- Импорт/экспорт проектов (ZIP-архивы)

### 6. Профили поставщиков

- Автоматическое создание профилей поставщиков
- Сохранение реквизитов для повторного использования
- Связывание файлов с профилями поставщиков

- **openpyxl/xlrd**: Работа с Excel

## API Endpoints

### Проекты
- `GET /api/projects` - Список проектов
- `POST /api/projects` - Создание проекта
- `PATCH /api/projects/{id}` - Обновление проекта
- `DELETE /api/projects/{id}` - Удаление проекта
- `POST /api/projects/import` - Импорт проекта
- `GET /api/projects/{id}/download` - Экспорт проекта

### Файлы
- `POST /api/storage/upload` - Загрузка файла
- `GET /api/storage/list` - Список файлов проекта
- `GET /api/storage/{name}` - Получение файла
- `PUT /api/storage/{name}` - Обновление данных файла
- `DELETE /api/storage/{name}` - Удаление файла

### Обработка
- `POST /api/process-invoice` - Обработка счета (SSE stream)
- `POST /api/match-items` - Сопоставление позиций
- `POST /api/v1/extract-layout` - Извлечение layout из OCR

### Поставщики
- `GET /api/suppliers/{project_id}` - Список поставщиков
- `POST /api/suppliers/{project_id}` - Сохранение поставщиков

### Конфигурация
- `GET /api/config` - Получение настроек
- `POST /api/config` - Сохранение настроек

### Экспорт
- `GET /api/export/history/{project_id}` - Экспорт истории (JSON)
- `GET /api/export/history-xlsx/{project_id}` - Экспорт истории (Excel)

## Особенности реализации

### 1. Drag & Drop
Глобальная поддержка перетаскивания файлов в любую область приложения с визуальным оверлеем.

### 2. Streaming обработка
Использование Server-Sent Events (SSE) для отображения прогресса обработки документов в реальном времени.

### 3. Иерархические данные
Поддержка древовидных структур в таблицах (разделы работ, группы материалов).

### 4. Валидация реквизитов
Встроенная валидация российских реквизитов:
- ИНН (10/12 цифр с контрольными суммами)
- КПП (9 цифр)
- БИК (9 цифр)
- Расчетные и корреспондентские счета (с проверкой по БИК)

### 5. Расчет стоимости AI
Предварительная оценка стоимости обработки документа через AI перед началом операции.

### 6. Кэширование
Сохранение промежуточных результатов обработки для возможности повторного использования.

## Конфигурация

Настройки хранятся в `server/config.json` и `server/client_settings.json`:
- API ключи Yandex Cloud
- Folder ID для Yandex Cloud
- Выбор моделей GPT (lite/pro)
- Настройки парсинга
